# ملاحظات الإصدار 2.4.0

يضيف هذا الإصدار مكتبة سياسات مالية متعددة وثابتة، يديرها الأدمن ويختار المستخدم من النسخ المنشورة، ويصحح تعريف النقطة المتوازنة حتى تبقى مستقلة عن السقف الفني.

أبرز التغييرات:

- إدارة جميع الافتراضات العامة القابلة للتقدير ضمن Policy Version ثابتة.
- استنساخ ونشر وتفعيل وأرشفة وإعادة نشر نسخ السياسات.
- اختيار المستخدم لنسخة السياسة المسموحة لكل تشغيل.
- تثبيت نسخة السياسة داخل Calculation Run والتقارير التاريخية.
- فصل Fair Floor وBalanced والسقف المتحفظ وTechnical Ceiling وResidual Equivalent والعرض الحالي.
- مطابقة الاقتصاديات الاسمية لمرجع البلاتفورم القديم، مع Technical Ceiling مطابق تقريباً وBalanced قريب ومستقل عن السقف.
- الحفاظ على واجهة إدخال بسيطة للمستخدم غير الخبير، مع بقاء النتائج المالية والتقارير كاملة.
