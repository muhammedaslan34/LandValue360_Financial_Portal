# Release Notes 1.0.0

Initial deployable release of the LandValue360 external client portal.

Includes:

- Landowner registration and project intake.
- Server-authoritative preliminary calculations.
- Private documents.
- Immutable submitted versions and revision workflow.
- Analyst/reviewer/manager operations.
- Canonical and internal-compatible `.lv360` exports.
- Report approval and publication.
- PostgreSQL RLS migration.
- Local SQLite launcher and Docker production deployment.
- Backup/restore, audit logging, notifications, OpenAPI, SBOM, and release verification.
