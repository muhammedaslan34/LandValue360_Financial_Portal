# دليل التشغيل اليومي

## الفحوص اليومية

- `/api/health/live` و`/api/health/ready`.
- اتصال PostgreSQL وحجم القاعدة وLocks طويلة المدة.
- سعة MinIO/S3 وفشل رفع أو تنزيل الملفات.
- Notification Outbox الفاشلة.
- عدد Calculation Runs الفاشلة ورسائل الخطأ.
- تطابق Engine Version النشطة مع Source Hash المثبت.
- مساحة القرص والذاكرة وCPU.

## فحوص مالية دورية

- تشغيل Golden Cases بعد كل تغيير في الكود أو الاعتماديات.
- مقارنة Result Hash لحالات مرجعية مثبتة.
- التأكد من أن كل Run تحفظ  Project/Policy/Engine references.
- فحص Terminal Debt وDeferred Costs وArrears في الحالات النموذجية.
- فتح تقرير PDF وExcel نموذجياً بعد كل إصدار.

## النسخ الاحتياطي

نفّذ نسخة يومية لقاعدة البيانات وObject Storage، واختبار استعادة دوري. قبل أي ترقية استخدم Pre-deploy Backup الذي يضيف نسخة المصدر الحي. النسخة غير المختبرة ليست Backup صالحاً.

## حادث حسابي

1. أوقف إنشاء تشغيلات جديدة إن كان هناك خطر على سلامة النتائج.
2. لا تحذف النتائج القديمة.
3. ثبت Run IDs وInput/Result Hashes المتأثرة.
4. عطّل Engine Version المخالفة وسجل إصداراً جديداً بعد الإصلاح.
5. أعد تشغيل Golden Cases واختبارات المصالحة.
6. لا تعيد حساب النتائج القديمة بأثر رجعي؛ أنشئ Runs جديدة واضحة.

## حادث نشر

أوقف الترقية، احتفظ بالسجلات، أعد الصورة السابقة، واستعد قاعدة البيانات/Object Storage من نسخة ما قبل الترقية عند الحاجة. وثق Root Cause والإجراء التصحيحي.
