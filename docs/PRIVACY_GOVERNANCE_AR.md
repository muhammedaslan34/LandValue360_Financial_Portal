# الخصوصية والحوكمة

يدعم النظام تسجيل الموافقات وطلبات تصدير البيانات وحذف الحساب. يجب اعتماد النصوص التالية من مستشار قانوني قبل الإطلاق:

- سياسة الخصوصية.
- شروط الاستخدام.
- الإقرار المهني.
- سياسة الاحتفاظ والحذف.
- سياسة معالجة مستندات الملكية.

حذف الحساب لا يعني حذف السجلات التي يجب الاحتفاظ بها لأغراض قانونية أو تدقيقية؛ يجب تطبيق السياسة المعتمدة حسب الدولة والجهة المالكة للبيانات.
