# ملاحظات الإصدار 2.2.0

## الهدف

هذا الإصدار هو خط الأساس المقترح لإطلاق LandValue360 Financial Portal. يحافظ على النموذج المالي الشهري المعتمد في الإصدار 2.1.0، ويضيف إدارة شاملة لمالك المنصة، وصولاً مدققاً لجميع المشاريع والتقارير، إدارة آمنة لاستعادة الحسابات والجلسات، شرحاً سياقياً ثنائي اللغة للمصطلحات، ومعالجة ضوضاء أخطاء الحفظ التلقائي.

## تجربة المستخدم

- تبقى المدخلات المالية المتقدمة مخفية عن المستخدم غير المتخصص.
- التمويل والمنحنيات وخطة التحصيل والتوقيت المتقدم تأتي من Financial Policy Version مثبتة.
- النتائج المالية تبقى كاملة: المشروع، المطور، صاحب الأرض، القيمة المتبقية، المجال التفاوضي والتدفقات النقدية.
- أضيفت أيقونة معلومات للمصطلحات المالية والمدخلات الأساسية، تعمل بالمرور أو لوحة المفاتيح أو اللمس.
- يمنع الحفظ التلقائي إرسال حقل رقمي فارغ أو قيمة مؤقتة غير صالحة أثناء الكتابة.

## إدارة المنصة

- يستطيع `PLATFORM_ADMIN` رؤية وفتح وتنزيل جميع المشاريع والتقارير والوثائق والتشغيلات لجميع المؤسسات.
- يظهر تنبيه واضح عند فتح مشروع بصلاحية مدير المنصة، وتسجل العملية في Audit Log.
- يستطيع المدير مراجعة المستخدمين والمؤسسات والعضويات والجلسات ومحاولات الدخول والنشاطات.
- يمكن إرسال رابط إعادة تعيين، أو إصدار كلمة مرور مؤقتة تظهر مرة واحدة وتفرض تغييرها عند أول دخول.
- لا يمكن للمدير رؤية كلمة المرور الأصلية أو Password Hash.
