# مسار التكامل مع LandValue360 Platform 2.1.1

1. البورتال يحفظ المشروع والنموذج المالي ويشغّل التحليل المالي الشهري المستقل.
2. النتائج المختصرة والتفاوضية والتدفقات تصدر من البورتال مباشرة.
3. عند الحاجة إلى التقارير المتقدمة، يصدّر المستخدم `internal.lv360`.
4. الحزمة تتضمن Platform-native snapshot مع منحنيات البيع والتحصيل والكلف والتمويل والعقد والسياسة الفعلية.
5. البلاتفورم يستورد المشروع كـ SHARED Draft ويعيد الحساب بالمحرك الكامل.
6. التقارير المتقدمة الناتجة يمكن رفعها وإدارتها ضمن Workflow البورتال الحالي.

الحزمة لا تعد بديلاً عن مراجعة المدخلات أو التقارير المتقدمة في البلاتفورم، لكنها لا ترسل افتراضات التمويل والكاش وحصة الأرض الصفرية القديمة.
