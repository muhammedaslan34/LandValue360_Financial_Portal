# ملاحظات الإصدار 2.0.0

## التحول الوظيفي

تحويل Client Portal 1.0.1 إلى Standalone Financial Portal من دون إنشاء بلاتفورم جديد.

## المضاف

- محرك شهري واحد Base Case من Platform 2.1.1.
- مؤشرات الجدوى للمشروع والمطور.
- Residual Land Value وLand Capacity DCF قبل الأرض.
- Optimization للمجال التفاوضي عبر ست آليات.
- Financial Policy Management بإصدارات تاريخية.
- سبعة جداول مالية مستقلة وترحيل `0006`.
- Calculation Runs ثابتة مع Project/Policy/Engine/Input/Result provenance.
- PDF وExcel ماليان.
- تصدير Platform-native بالافتراضات الفعلية.
- Golden Cases وCore Parity وSample Reports.
- Pre-deployment backup للمصدر وقاعدة البيانات والتخزين.

## غير المضاف

السيناريوهات، Sensitivity، Monte Carlo، واجهة المخاطر، المقارنات السوقية، مقارنة البدائل التخطيطية، المناقصات الحكومية الكاملة، والتقارير المتقدمة الخاصة بالبلاتفورم.
