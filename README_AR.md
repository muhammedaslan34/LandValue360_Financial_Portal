# LandValue360 Financial Portal v2.5.0

بوابة مالية مستقلة مبنية على FastAPI وPostgreSQL/SQLite ومحرك LandValue360 الشهري 2.1.1. صُممت لمستخدم غير خبير: مدخلات المشروع الأساسية تبقى بسيطة، بينما يعمل المحرك المالي المتقدم على الخادم ويعرض الجدوى المالية كاملة للمشروع والمطور وصاحب الأرض.

## الوظائف الرئيسية

- نموذج مالي شهري واحد مع تدفقات شهرية وسنوية.
- فصل اقتصاديات المشروع والمطور وصاحب الأرض.
- Project IRR/NPV وDeveloper Equity IRR/NPV وMOIC والربحية والسيولة.
- Residual Land Value وLand Capacity DCF قبل مقابل الأرض.
- ست آليات تعاقدية: إجمالي المبيعات، صافي المبيعات، مشاركة الربح، دفعة مقدمة، عقد هجين وضمان أدنى.
- مجال تفاوض يبدأ من **الحد الأدنى المقبول** ويعرض النقطة المتوازنة، القيمة المتبقية المكافئة، السقف المتحفظ وفق السياسة، العرض الحالي والسقف الفني.
- شرح تلقائي لسبب كل حد وطريقة حسابه والقيد الحاكم.
- PDF رسمي من 11 صفحة وExcel تحليلي من خمس أوراق.
- إدارة المستخدمين والمؤسسات والمشاريع والتقارير من حساب مدير المنصة.

## السياسات المالية متعددة النسخ

يدير الأدمن مكتبة `Financial Policy Versions` ثابتة وغير قابلة للتعديل بأثر رجعي. يستطيع استنساخ أي نسخة، تعديل جميع الافتراضات التقديرية، نشرها، جعلها قابلة لاختيار المستخدم، تفعيلها كنسخة افتراضية، أرشفتها وإعادة نشرها.

يختار المستخدم إحدى النسخ المنشورة والمسموح بها قبل تشغيل التحليل. يحتفظ كل Calculation Run بصورة كاملة من السياسة المختارة، لذلك لا تتغير النتائج القديمة بعد تعديل السياسات المستقبلية.

تشمل الافتراضات القابلة للإدارة: معدلات الخصم، حدود IRR/NPV/MOIC والربحية، قواعد استرداد قيمة الأرض، مجال البحث، منهج التفاوض، التمويل والسيولة، منحنيات البيع والكلف، خطة التحصيل، الحسومات والمردودات، قواعد الإنفاق والتوزيع، الاحتياطيات وحدود Solver.

لا يمكن تعطيل قواعد سلامة النموذج: منع الكاش السالب غير المغطى، إقفال الدين، تصفير الكلف المؤجلة والمتأخرات، والمصالحة النقدية الشهرية.

## بساطة المستخدم

لا يرى المستخدم العادي إعدادات التمويل أو المنحنيات أو تفاصيل بناء النموذج، لكنه يرى النتائج المالية والجدوى والتقارير كاملة. أزيلت مساحة إدارة حالة المحلل من هذا الإصدار لأنها ليست جزءاً من رحلة المستخدم الحالية.

## التشغيل المحلي على Windows

1. فك ملف ZIP في مجلد جديد.
2. شغّل:

```powershell
.\START_PORTAL.bat
```

3. افتح العنوان الذي يظهر في نافذة التشغيل.

## التحقق قبل النشر

```bash
python scripts/verify_release.py
python scripts/runtime_preflight.py
python scripts/validate_policy_negotiation_v250.py
python scripts/validate_v250_scenarios.py
alembic upgrade head
```

## حدود النشر

الحزمة لا تحتوي أسرار الإنتاج أو إعداد الدومين وTLS. يلزم ضبط PostgreSQL والتخزين الخاص وSMTP ومتغيرات البيئة، ثم تنفيذ النسخ الاحتياطي وStaging قبل Production.
